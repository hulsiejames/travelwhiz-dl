Quick start
===========

Installation
------------

After the package is published, install it with pip:

.. code-block:: sh

   pip install travelwhiz_dl

For a development checkout, clone the repository and install the development extras:

.. code-block:: sh

   git clone https://github.com/hulsiejames/travelwhiz-dl
   cd travelwhiz-dl
   python -m pip install -e ".[dev,docs]"

First use
---------

.. code-block:: python

   import travelwhiz_dl
